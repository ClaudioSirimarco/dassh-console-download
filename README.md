# DASSH Console — download

Terminal em abas (Serial, SSH, PowerShell, CMD, Azure, GCP e Web/iDRAC) com evidências padronizadas,
relatório PDF e sessão ao vivo. **DASSH IT Services.**

## ⬇ Baixar (Windows 10/11, 64 bits)

**[Baixar o instalador mais recente](https://github.com/ClaudioSirimarco/dassh-console-download/releases/latest)**

- `DASSH-Console-Setup-x.y.z.exe`: instalador. É o recomendado e não precisa ser administrador.
- `DASSH-Console-Portatil-x.y.z.zip`: versão portátil, para rodar de uma pasta ou pendrive.

## Recebeu um convite para uma sessão ao vivo?

1. Instale e abra o DASSH Console.
2. Clique em **🔗 Entrar**.
3. Digite o código que veio no convite (ex.: `ABCD-EFGH-JKLM`).

Você entra como **observador**. Quem convidou aprova a sua entrada e decide quem digita no terminal.
A conexão é criptografada de ponta a ponta.

> **Aviso do Windows:** enquanto o instalador não tiver assinatura digital, o Windows pode mostrar
> "O Windows protegeu o computador". Nesse caso, clique em **Mais informações → Executar assim mesmo**.
